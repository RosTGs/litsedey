# Первое движение в Kadr

1. Запустите редактор по README. В новом рабочем пространстве откроется «Бот · первые движения».
2. Нажмите ▶ под холстом: бот перемещает голову, моргает и дышит. Остановите воспроизведение.
3. В разделе «Модель» найдите параметр «Левый глаз». Значение 1 открывает глаз, 0 закрывает. Стороны обозначены со стороны персонажа.
4. Попробуйте «Открытие рта» и «Наклон головы». «Поворот головы X» в этом учебном примере показывает простое перемещение; перспективный поворот нужно создавать отдельными формами.
5. Сделайте копию проекта кнопкой рядом с выбором проекта. Выберите слой «Рот», включите сетку и инструмент M. Правка базовой формы меняет основу; для формы параметра сначала включите режим записи ключевой формы.
6. Используйте отмену, если результат не подходит. Приближение — колесом, перемещение холста — инструментом H, обзор — «Уместить».
7. Откройте «Экспорт» и сохраните «Проект со всеми ресурсами». Через «Импорт файлов» откройте ZIP обратно — появится отдельная копия с рисунками и формами.

Для своего персонажа начните с PNG на прозрачном фоне или RGB PSD с обычными растровыми слоями. Для моргания и взгляда подготовьте белок, радужку, веко и закрытую форму каждого глаза, затем откройте «Быстрая сборка». Подробное описание инструментов — в [статье](experiment-ru.md).
