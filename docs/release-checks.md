# Проверка публичной версии 0.4

Пакет проверен в отдельной папке и новом Python-окружении. Пользовательские проекты не используются для запуска или автоматических тестов.

| Проверка | Результат |
|---|---|
| Установка `requirements.txt` | Успешно, Python 3.9.6 на macOS |
| `python -m unittest discover -s tests -v` | 59 тестов прошли; Node.js 20.20.0 для проверок JavaScript |
| Учебный пример | Отдельное моргание, изменение рта, перенос геометрии/форм и пикселей через ZIP |
| Экспорт примера | ZIP, PNG, PSD, анимация и выражение; экспорт физики без её настройки выдаёт понятную ошибку |
| Браузер | Чистый запуск, отображение бота, воспроизведение, сохранение настроек и ZIP через интерфейс |
| macOS-оболочка | `build_app.py` собирает локальный неподписанный `Kadr.app` |
| Публичные файлы | Проверен явный набор исходников; данные, ключи, окружение и рабочие архивы исключены |
| Сторонние файлы | Сохранены лицензии, источники и SHA-256; JS/WASM сопоставлены с npm-пакетом |

Проверки не доказывают готовность автономного установщика или всех платформ. Реальная камера и платная генерация в этой итерации не запускались. В зафиксированной версии `psd-tools` есть предупреждение об устаревающем аргументе Pillow; тесты экспорта проходят с зависимостями из `requirements.txt`.
