# Процесс работы с Мирой

15 настоящих снимков Лицедей 0.4, 9 ноября 2026. Размер каждого — 1280 × 720. Интерфейс не генерировался и не ретушировался. Все действия выполнял AI-помощник в отдельной демонстрационной копии.

Снимки 01–08 воспроизводят импорт и сборку глаз из подготовленных нейросетевых деталей. Снимки 09–11 показывают уточнённую модель, 12–15 — подготовку девятисекундной анимации, экспорт и повторный импорт. Ключи дыхания на снимках относятся к рабочей итерации до небольшой финальной коррекции нижнего значения. Итоговые файлы движения находятся в media и examples.

Порядок снимков соответствует номерам файлов; подробные действия и критерии проверки описаны в статье mira-process-ru.md.
